A matriz das aulas e a matriz de competências têm finalidades diferentes: a
primeira roteia os 425 itens da Udemy; a segunda audita individualmente cada
Knowledge/Skill do guia oficial. Nenhuma delas deve ser interpretada como
previsão da frequência de questões no exame.

O roteiro diário é gerado a partir do inventário e cobre 396 aulas numeradas,
28 quizzes e o practice exam. Use os números de aula para localizar o conteúdo
na Udemy; `indice_item` é apenas uma chave interna do CSV.
